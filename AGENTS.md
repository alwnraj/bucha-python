# Repository agent entry point

Read and follow `agent.md` before working in this repository. Read `handoff.md` for the current state, keep the journal in `session.md` up to date and `README.md` for setup and execution.

The user's standing constraints are: no subagents, no overengineering, no edits for question-only requests, and no latest-package downloads. Any downloaded package version must be explicitly pinned and at least two weeks old.
